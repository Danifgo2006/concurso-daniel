# Quiz DieF

Práctica de Desarrollo Web en Entorno Cliente.

Quiz DieF es un concurso de preguntas sobre fútbol, música y cultura pop.

## Funcionamiento

El jugador introduce su nombre antes de comenzar la partida.

Las preguntas se cargan desde un archivo JSON y se muestran de forma aleatoria. Las respuestas también aparecen en orden aleatorio.

El concurso está dividido en rondas. Para pasar a la siguiente ronda hay que responder correctamente todas las preguntas.

Si el jugador falla alguna respuesta, la partida termina.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- JSON
- Fetch
- LocalStorage
